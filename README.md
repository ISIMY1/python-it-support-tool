# Python IT Support Ticket Tool

## Overview
A beginner Python project designed to practise automating common IT support workflows.

## Features
- Collects user and device information
- Records a description of the issue
- Generates a ticket summary
- Applies basic ticket triage logic

## Technologies
- Python
- Visual Studio Code
- Git and GitHub

## What I'm Learning
- Variables and data types
- User input and conditional statements
- Input validation
- File handling and automation

## Future Improvements
- Add ticket priority levels
- Save tickets to a CSV file
- Add error handling
- Generate ticket statistics

## Disclaimer
This is an independent learning project using fictional data. It does not connect to any production IT systems.
